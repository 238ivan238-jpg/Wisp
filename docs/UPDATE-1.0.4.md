# Wisp 1.0.4 — обработка диктовки и списки

`app.wisp.voice`, versionCode 5. Обновление доступно через настройки Wisp 1.0.3. Прежний сертификат подписи сохраняет совместимость установки и пользовательские настройки.

## Причина и исправления

В сообщении пользователя обнаружено точное совпадение со служебным текстом, отправлявшимся Whisper как подсказка: `Russian and English, including mixed technical terms.` Такая подсказка могла попадать в расшифровку. Теперь без пользовательского словаря поле `prompt` отсутствует в запросе распознавания; при наличии словаря отправляются только его слова (до 500 символов), без служебного вступления. В режиме авто язык не фиксируется. Фильтра удаления английских фраз из ответа нет: пользователь может произнести их намеренно.

Прежние правила очистки ограничивались пунктуацией и очевидными оговорками; списки были заданы только отдельному режиму заметок. Новые правила редактора охватывают грамматику и синтаксис, слова-паразиты, незавершённые начала фраз, явные самоисправления и автоматические списки в обычном режиме. Есть конкретные примеры преобразований. Различаются перечисления, обычная связная речь и тестовый счёт; факты, отрицания, степень уверенности, тон и смешанные языки должны сохраняться. Модель и параметры генерации не изменены.

Словарь имён/терминов теперь передаётся также в редактор. Диктовка и словарь кодируются отдельными полями JSON в пользовательском сообщении, вне системных инструкций; словарь используется только для соответствующих произнесённых слов. Вопросы и просьбы в диктовке остаются текстом, который нужно отредактировать. Модель не должна отвечать на них или выдумывать содержание.

Режим по умолчанию переименован из «Чистый текст» в «Умный текст»; «Письмо» — в «Сообщение», «Заметка» — в «Список». Идентификаторы и сохранённый выбор прежние. В «Без ИИ» редактор по-прежнему не вызывается. Интерфейс диктовки остаётся единственным плавающим микрофоном.

## Проверки сборки

`bash scripts/setup-cloud.sh` завершился успешно: `assembleRelease`, `testDebugUnitTest`, `lintDebug`, `lintRelease`. 71 тест: 0 падений, ошибок и пропусков. Lint: 0 ошибок, 7 предупреждений в каждом варианте, того же типа, что в 1.0.3. Apksigner подтвердил подпись v2 прежним сертификатом.

Регрессионные проверки охватывают отсутствие подсказки без словаря, отсутствие служебного префикса при словаре, сохранение намеренно произнесённого английского текста, отделение словаря/диктовки от системных инструкций, передачу словаря резервной модели, полный двухэтапный путь и автоматическую вставку многострочного списка с английскими терминами. Тестовые пакеты обновления теперь явно фиксируют сценарий 1.0.3 → 1.0.4 независимо от текущего номера сборки.

Ответы модели в этих тестах заданы транспортными фикстурами. Они подтверждают запросы, обработку ответа и вставку. Реальное качество редактирования и распознавания на личном ключе Groq в облачной среде не оценивалось.

После публикации коммита `e5157759533dbc2d333cd886915c4ec9fb73987f` выполнен `verify-update-channel.py`: настоящий Java-клиент получил `DOWNLOAD_VERIFIED 1.0.4`, проверил хеш/кеш и затем `UP_TO_DATE 1.0.4`. Загруженный APK совпадает с локальной сборкой по SHA-256. Отдельно проверена прямая GitHub-ссылка на APK. Установка на физическом телефоне этой проверкой не выполнялась.

## Примеры для проверки на телефоне

Режим: «Умный текст», язык: «русский + English (авто)». Эталон описывает ожидаемый результат; формулировки и пунктуация могут незначительно отличаться.

1. «Ну мне нужно купить первое молоко второе хлеб третье кофе» → вступление и нумерованный список из трёх покупок, без «ну».
2. «На завтра список проверить pull request потом обновить README и запустить unit tests» → три отдельных пункта с сохранёнными английскими терминами.
3. «Встреча в четверг нет в пятницу в три budget не меняем» → пятница, время «в три», сохранённое отрицание «budget не меняем».
4. «Ну я я думаю что этот API не работает можешь пожалуйста проверить endpoint» → исправленная пунктуация и повтор, просьба остаётся просьбой, без выдуманного ответа.
5. «Просто проверка один два три четыре пять» → обычная строка со счётом, без списка задач.
6. «Please review the pull request and don't change the API. Потом запусти unit tests» → два языка без перевода, отрицание и API сохранены.

Если обработка завершится ошибкой, Wisp вставит исходную расшифровку и покажет причину. Уже сохранённый режим «Без ИИ» при обновлении не переключается автоматически.
