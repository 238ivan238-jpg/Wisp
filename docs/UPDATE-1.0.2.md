# Wisp 1.0.2: совместимость ИИ-очистки

Пользователь подтвердил реальное распознавание речи на Pixel; на этапе очистки Groq вернул 400 или 404. Версия 1.0.1 объединяла эти статусы, скрывая тело ответа, поэтому точная исходная причина отказа неизвестна. Нельзя утверждать, что Llama была удалена или отключена у пользователя.

В 1.0.2 предпочтительная модель — `openai/gpt-oss-20b`, как в актуальном README официального SDK Groq. Устаревший параметр `max_tokens` заменён на `max_completion_tokens`; GPT-OSS получает поддерживаемый `reasoning_effort: low`, альтернативы Llama не получают этот параметр. Если ответ явно сообщает о недоступности/выводе модели из эксплуатации, приложение получает `/models` и пробует только совместимые альтернативы из этого списка. Ошибки авторизации, лимитов, общего запрета доступа и параметров не повторяются как ошибки моделей. Неуспешная очистка по-прежнему сохраняет исходную расшифровку.

Диагностика показывает HTTP-статус и ограниченный безопасный идентификатор ошибки, без произвольного сообщения, тела ответа или ключа. Кнопка «Проверить» проверяет доступность Whisper в списке моделей и выполняет очистку фиксированной короткой тестовой фразы. Это явно указано в интерфейсе; аудио при проверке не записывается.

Источники:
- https://github.com/groq/groq-python/blob/main/README.md — пример `openai/gpt-oss-20b`.
- https://github.com/groq/groq-python/blob/main/src/groq/types/chat/completion_create_params.py — `max_completion_tokens`, deprecated `max_tokens`, допустимые `reasoning_effort` для GPT-OSS.
