# Wisp 1.0.12 — вкладки и более активные эмодзи

`app.wisp.voice`, versionCode 13. Прежняя длинная страница заменена постоянной нижней навигацией: «Голос», «Словарь», «Статистика», «Диагностика», «Настройки». Дизайн и снимки — в [DESIGN-1.0.12.md](DESIGN-1.0.12.md).

«Голос» показывает язык, обработку, эмодзи, Turbo и короткую подсказку EN. Для нового подключения есть одна кнопка; после готовности она скрывается. В «Настройках» — компактные строки подключения, ключа Groq, обновлений и прежней клавиатуры. Подробности доступны только после нажатия; помощь с разрешениями раскрывается отдельно. Словарь вынесен в собственный редактор с явным сохранением. Несохранённый черновик сохраняется при смене вкладок и восстановлении Activity. Введённый API-ключ не включается в сохранённое состояние UI и не показывается обратно из хранилища.

Статистика сразу открывает общие показатели и график за 7/30/365 дней. Списки слов-паразитов и технических ошибок раскрываются. Диагностика сразу показывает последние события и действия Share/Save. Подтверждения очистки сохранены. Пробное поле, большие рекламные заголовки, цифровые блоки 01/02/03 и длинный нижний текст удалены.

Updater создаётся один раз на MainActivity и сохраняется при переходах между страницами. Автопроверка, кеширование APK, восстановление разрешения установки, проверка пакета/версии/сертификата и SHA-256 работают по-прежнему. Проверка и установка теперь в «Настройки» → «Обновления». Системные разрешения и выбор Gboard остаются ручными. Нижняя навигация находится вне ScrollView и учитывает системные панели/вырезы.

Эмодзи по-прежнему выключены по умолчанию; сохранённый выбор не сбрасывается. При включении системное правило теперь просит активнее оформлять обычные сообщения: обычно 1–3 эмодзи для короткой фразы, до 4–6 для длинного текста, можно рядом с реальными пунктами списка. Смысл, слова, числа и маркеры списков сохраняются; существующие эмодзи учитываются без повторов. Для болезни, горя, опасности, конфликтов и строго формального/кодового текста оставлено исключение. Это инструкция модели, не жёсткий постфильтр и не обещание оценённого качества живого Groq. Дополнительного запроса для эмодзи нет.

Кнопка EN, пятиминутный лимит, совместимость с полями без чтения контекста, ограничения чувствительных полей, локальные статистика/диагностика и подпись обновлений сохранены. Физический Pixel и живые запросы Groq в облаке не проверялись. Снимки экранов и тесты не выдаются за такую проверку.

`bash scripts/setup-cloud.sh`: release-сборка, подпись v2 и 148 тестов успешно завершены; 0 падений, ошибок и пропусков. Lint debug/release: по 0 ошибок и 12 предупреждений без подавления. Проверены отсутствие длинной ленты на первом экране, минимальные области нажатия/подписи нижних вкладок, прямое открытие данных статистики и диагностики, черновик словаря при переходах/восстановлении, отсутствие ключа в UI state, сохранение экземпляра updater и повторное использование проверенного кеша при возврате из системного разрешения установки.

Native Graphics отрисовал шесть экранов на размере Pixel; снимки светлой/тёмной темы просмотрены. Издатель подтвердил прежний сертификат, пакет и версию.
