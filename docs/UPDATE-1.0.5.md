# Wisp 1.0.5 — один редактор «Чистый текст»

`app.wisp.voice`, versionCode 6. Обновление через настройки Wisp 1.0.3+. Сертификат подписи прежний; APK устанавливается поверх предыдущей версии.

По запросу пользователя убраны отдельные режимы письма/сообщения и заметки/списка. В настройках остался переключатель «Чистый текст», включённый по умолчанию. Общие правила редактора: грамматика и оговорки, слова-паразиты и случайные повторы, знаки препинания и абзацы, автоматические списки для перечислений. Русский и английский сохраняются без перевода; факты, отрицания и тон должны сохраняться. Отдельные указания модели принудительно оформлять каждую диктовку заметкой или письмом удалены.

Пунктуация передаёт смысл и интонацию, доступные по словам и контексту расшифровки. Текстовый редактор не анализирует звучание аудио: аудио получает Whisper, редактор получает текст. Поэтому восстановление интонации не является отдельной гарантированной аудиофункцией.

Старые сохранённые `message`, `notes` и `clean` используют общий редактор. Если пользователь раньше выбрал `raw` («Без ИИ»), переключатель остаётся выключенным. Его выключение даёт обычную расшифровку без запроса к текстовой модели. Ключ, словарь, язык и оформление плавающего микрофона сохраняются.

Это упрощение режимов. Причина отсутствия ожидаемого редактирования на конкретном телефоне ещё требует подтверждения версии, настройки и результата запроса Groq. Сохраняется прежний путь: при ошибке обработки вставляется исходная расшифровка с сообщением об ошибке.

## Проверки

`bash scripts/setup-cloud.sh` успешно выполнил `assembleRelease`, `testDebugUnitTest`, `lintDebug`, `lintRelease`. 72 теста: 0 падений, ошибок и пропусков. Lint: 0 ошибок, 7 предупреждений в каждом варианте сборки, тех же типов, что ранее. Подпись APK v2 подтверждена.

Тесты проверяют переход старых вариантов обработки на общий редактор, отсутствие их кнопок в настройках, включение по умолчанию, сохранение выключенной обработки и переключение с повторным открытием экрана. Ранее действующие проверки передачи словаря, многострочных списков, смешанных языков, ошибок очистки, отмены, вставки и обновлений проходят. Удалён тест разных инструкций прежних режимов, поскольку эти режимы и инструкции удалены.

Транспортные фикстуры подтверждают путь данных, а не качество живой языковой модели. Диктовка на физическом Pixel и вызов Groq личным ключом здесь не выполнялись.

После публикации канал проверяется командой `python3 scripts/verify-update-channel.py`: реальный клиент получает метаданные, скачивает APK для старой версии, сверяет SHA-256/кеш и определяет уже актуальную версию. Установка на телефон подтверждается Android отдельно.

Для опубликованной 1.0.5 эта проверка завершилась успешно: `DOWNLOAD_VERIFIED 1.0.5`, затем `UP_TO_DATE 1.0.5`; SHA-256 совпал с локальной сборкой.
