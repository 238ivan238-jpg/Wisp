# Wisp 1.0.6 — статистика и перевод на английский

Пакет `app.wisp.voice`, versionCode 7. Содержит единый «Чистый текст» из 1.0.5, локальную статистику и отдельный перевод, запрошенные пользователем. Обновление устанавливается поверх прежних APK тем же сертификатом.

## Настройки перевода

«Переводить на английский» выключен по умолчанию. Включение включает обработку текста; выключение «Чистый текст» выключает перевод. Выбор сохраняется при повторном открытии настроек. Старые настройки письма/заметки по-прежнему используют общий редактор, а ранее выключенный редактор остаётся выключенным.

Whisper возвращает расшифровку, после чего текстовая модель одним запросом редактирует и переводит её на естественный английский. Смешанные русские/английские фразы также переводятся в связный английский. Правила требуют сохранять факты, числа, отрицания, имена, технические термины, порядок и тон; вопросы/просьбы переводятся как текст, без ответа на них. Диктовка и словарь остаются пользовательскими данными вне системных инструкций.

Резервная модель при явной недоступности основной получает ту же задачу перевода. Лимиты, авторизация и прочие сбои не вызывают бесконечных повторов. При ошибке сохраняется исходная расшифровка с сообщением «Перевод не удался»; она вставляется автоматически по прежним правилам. Отмена не приводит к вставке запоздалого результата. Кнопка проверки ключа отправляет короткую фиксированную фразу для выбранной обработки/перевода; успешный ответ подтверждает доступ, а не точность языка.

## Статистика

Открывается отдельной кнопкой в настройках. Есть:

- Общие счётчики диктовок, вставленных слов и времени записи.
- Графики по дням за 7 или 30 дней, с выбором «Диктовки», «Слова», «Минуты». Доступный текст графика содержит каждое дневное значение.
- Частоты известных слов-паразитов, фактически удалённых редактором в успешной обычной очистке.
- Частоты технических сбоев: ключ, доступ, оплата/лимиты, модель, сеть/TLS/тайм-аут, ответ сервера, микрофон и вставка.
- Сброс статистики отдельной кнопкой с подтверждением.

Диктовка считается после успешной остановки пригодной записи (не короче 650 мс), до запроса распознавания. Время — длительность записи до двух минут, не длительность запроса и не оценка времени звучания речи. Слова считаются только после успешного `InputConnection.commitText`. Смена поля/отмена и отклонённая вставка не увеличивают счётчик слов. Запись относится к дню её начала в часовом поясе телефона.

Дневные данные ограничены последними 90 днями; общие счётчики сохраняются. Учёт начинается с этой версии, прошлое использование не восстанавливается. Хранятся только численные агрегаты, фиксированные категории ошибок и известные выражения, без текстов, аудио, API-ключей, произвольных имён/адресов/ошибок сервера. Статистика не передаётся на сервер.

Частоты слов-паразитов получаются сравнением количества известных выражений до/после очистки с границами слов. Это наблюдение за удалениями редактора, без оценки правильности решения модели. Перевод, отключённая обработка и аварийный возврат исходного текста исключены из этой частоты. Ошибки грамматики не классифицируются автоматически: раздел ошибок показывает технические сбои.

Точность языка нужно оценить на реальной диктовке. Плавающий интерфейс по-прежнему состоит из одного микрофона; дополнительных кнопок в нём нет.
