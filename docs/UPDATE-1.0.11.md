# Wisp 1.0.11 — поля без чтения контекста

`app.wisp.voice`, versionCode 12. Пользователь получил в активном поле Messenger сообщение «Это поле не поддерживает вставку рядом с Gboard. Используйте прежний режим Wisp». Оно возникало до записи: Wisp трактовал null из getSurroundingText(0, 0, 0) как отсутствие поддержки любого ввода. Публичный Android API разделяет чтение контекста и commitText; первое не является обязательным условием второго.

Предварительное чтение перед записью удалено. Проверка существования подключения, активного редактора, паролей и блокировки сохранена. После обработки попытка прочитать контекст остаётся полезной для пробелов и подтверждения. При null или UnsupportedOperationException передаётся один commitText с самой диктовкой: позицию курсора/выделение обрабатывает редактор. Без контекста пробелы не добавляются автоматически. Неправильные границы в непустом ответе чтения по-прежнему отклоняются.

Без чтения результат — SENT_WITHOUT_CONTEXT, в журнале CONTEXT_UNAVAILABLE и UNCONFIRMED. Повторной отправки, замены всего поля, чтения дерева экрана, буфера обмена или автоматической отправки сообщения нет. Неподтверждённые слова не добавляются в статистику. Короткая надпись «Текст передан в приложение» сообщает о передаче вызова, не утверждая подтверждение редактором. Ошибки обработки/перевода при этом остаются видимыми. Закрытый/изменившийся редактор отменяет ожидающую вставку.

Регрессионные сценарии: недоступное чтение при работоспособном commitText; позиция в середине текста и обратное выделение; многострочный перевод/эмодзи; неподдерживаемое чтение после commit; отсутствие повторов и ложного подтверждения; неправильные границы/нет подключения/пустой результат. Robolectric использует настоящий AccessibilityInputConnection и RemoteAccessibilityInputConnection с фикстурным AIDL-редактором, который возвращает null для чтения, но принимает commit. Проверяются запуск обеих кнопок без чтения, однократная передача, сохранение предупреждения, журнал без текста, отсутствие подтверждённого счётчика и запрет вставки в закрытый редактор.

Кнопка EN, эмодзи, пятиминутный лимит и прежний способ клавиатуры сохранены. Реальный Messenger, аппаратный микрофон Pixel и живой Groq не запускались в облаке: совместимость с установленной у пользователя версией Messenger нужно повторно проверить после обновления.

`bash scripts/setup-cloud.sh` успешно завершил release-сборку, 139 тестов (0 падений, ошибок и пропусков), lintDebug и lintRelease (по 0 ошибок и 13 прежних предупреждений), проверку подписи v2. Издатель подтвердил совпадение сертификата и метаданные APK.
