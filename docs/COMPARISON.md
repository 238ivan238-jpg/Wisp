# Сравнение и принятые решения

Сравнивались исходники **VoiceKeys.zip**, код из **wisprpixel_android_keyboard_project.md**, наша реализация Wisp и доступный официальный README FUTO Voice Input. Присланные реализации изучались как код: их APK не запускались. Тестов точности или скорости на одинаковых аудиозаписях нет, поэтому утверждений «лучше распознаёт» или «быстрее конкурента» здесь нет.

## Присланные альтернативы

| Область | VoiceKeys.zip | Wispr Pixel из Markdown | Wisp |
|---|---|---|---|
| Диктовка | Удержание микрофона; AAC/M4A | Удержание и нажатие; PCM/WAV | Нажатие/удержание, AAC/M4A, таймер и лимит 2 минуты |
| Языки | Auto/RU/EN | Подсказка для смешанной речи | Auto/RU/EN, подсказка RU/EN и пользовательские термины |
| Очистка | Вкл/выкл; gpt-oss-20b | Чистый/сообщение/заметка/raw; Llama | Чистый/письмо/заметка/raw; Llama, оригинал доступен для сравнения |
| Вставка | Автоматически после ответа | Автоматически после ответа | По кнопке после предпросмотра; не отправляет сообщение автоматически |
| Хранение ключа | Обычные SharedPreferences | Обычные SharedPreferences; allowBackup=true | AES-GCM + Android Keystore; резервное копирование и перенос отключены |
| Скрытие клавиатуры | Есть остановка записи и отмена coroutine в onFinishInputView | Остановка записи только в onDestroy; onFinishInputView/onWindowHidden отсутствуют | Остановка в жизненном цикле ввода, закрытие запроса, сброс результата и проверка поколения сессии |
| Временные записи | В просмотренном Recorder/VoiceIME нет удаления после запроса | Удаление после transcribe, но нет универсального finally для всех путей | Удаление после запроса, отмены и старых файлов при запуске службы |
| Ошибка очистки | Возвращается исходный текст | Возвращается исходный текст | Исходный текст плюс видимое сообщение; обрезанный ответ не принимается за полный |
| Отмена вставки | Нет | Проверяет совпадение текста перед курсором | Проверяет совпадение и отсутствие выделения; сбрасывается между полями |
| Удаление | KeyEvent DEL | deleteSurroundingText(1,0) | Удаление выделения или Unicode code point; автоповтор |
| Ручной ввод | Пробел/Enter/удаление | Пробел/Enter/удаление | Также простые буквы RU/EN и цифры; для полного набора функций есть возврат к Gboard |
| Проверка работоспособности | В архиве нет тестов и APK; Gradle Wrapper без jar и запускающего скрипта | Документ с файлами; заявление «полностью собранный» не подтверждено артефактом | APK действительно собирается; JUnit/Robolectric и Android Lint запускаются отдельно |

Это решения для личного Android-приложения, а не перенос одной из реализаций без проверки. Из VoiceKeys взяты идеи простого M4A-потока и явного выбора языка; из Markdown — режимы, словарь и отмена; дополнены контролем сессии, защитой ключа, предпросмотром и воспроизводимой сборкой.

## Внешние продукты

**Wispr Flow** — функциональный ориентир, который описан в пользовательском задании: речь, очистка и ввод в приложения. Его актуальная Android-реализация и тарифы не проверены: `wisprflow.ai/android` недоступен через сетевую политику этой машины (HTTP 403 от прокси). Числа из предыдущей переписки не используются как актуальные цены. Wisp не связан с Wispr Flow и не заявляет полного совпадения возможностей.

**FUTO Voice Input / FUTO Keyboard** — альтернативный подход для тех, кому нужны локальные модели и интеграция с другими клавиатурами. Доступный [официальный README](https://github.com/futo-org/voice-input) описывает Whisper, русский и английский, голосовой IME и RECOGNIZE_SPEECH. Он также прямо указывает: Gboard использует собственное распознавание и не поддерживает такой сторонний голосовой движок; разработка в основном переместилась в FUTO Keyboard. Поэтому Wisp сделан самостоятельной переключаемой клавиатурой, а не заменой микрофона внутри Gboard. Сайт FUTO недоступен через прокси; установленное приложение не тестировалось.

**Gboard** оставлен доступным как основная клавиатура для обычного ввода, свайпов, автозамены и других привычных функций. Wisp дополняет этот сценарий специализированной диктовкой. Страница справки Google также недоступна через прокси; сравнительный замер диктовки Gboard не проводился.

## Что сознательно не включено

- Оффлайн-модель: пользователь допускает облако, а скачивание моделей и поддержка native-инференса увеличили бы размер и сложность первой версии.
- Плавающая кнопка и Accessibility Service: установка через IME решает ввод без доступа к экрану других приложений.
- Автоматическая отправка сообщений, скрытая фоновая запись и история диктовок: для требуемого сценария не нужны.
- Обещание бесплатного Groq: доступ и лимиты зависят от аккаунта и могут изменяться. Приложение показывает ошибки ключа/лимитов, а не маскирует их.

## Следующая реальная оценка качества

На Pixel 9 с собственным ключом продиктуйте одинаковые короткие фразы в Wisp и привычную клавиатуру: только RU, только EN, смешанный технический текст, самокоррекцию («во вторник, нет, в среду») и фразу с именем из словаря. Сравните смысл, термины и время ожидания; для Wisp сравните Large v3/Turbo и исходный/очищенный текст. Этот эксперимент пока не выполнен, результаты не выдумываются.
