# Wisp 1.0.3 — плавающий микрофон и обновления

Пакет `app.wisp.voice`, versionCode 4, Android API 28+. Установка поверх прежней версии сохраняет настройки и ключ. Один раз нужно установить APK вручную; функция обновлений появляется только в этой версии.

## Изменения по запросу пользователя

- Вместо панели клавиатуры — единственный перемещаемый микрофон. Нажатие начинает/останавливает запись, удержание открывает настройки. Положение сохраняется.
- Запись ограничена двумя минутами; таймер появляется при записи. После распознавания и выбранной обработки текст автоматически вставляется в активное поле. Отправка сообщения не выполняется.
- Убраны заголовок, языковые/режимные кнопки, ABC, предпросмотр, отмена, ручная вставка и ряд обычных клавиш. Язык/обработка доступны в настройках.
- Чёрно-белое оформление следует системной светлой/тёмной теме. Прозрачная область вне значка пропускает касания; системная навигационная область исключена из положения микрофона. Используются публичные API InputMethodService, без отдельного overlay/Accessibility-разрешения.
- Кнопки проверки и скачивания обновлений находятся в настройках. Автопроверка при открытии включена по умолчанию, не чаще раза в шесть часов. Скачивание — по кнопке, установка — через подтверждение Android. При первом запросе разрешения Wisp продолжает установку после возврата, повторно проверив кеш.
- Проверяются размер/SHA-256 загрузки, пакет, версия и сертификат установленного приложения. Чужие/повреждённые APK, откаты версии и несовпадающий подписант отклоняются. Ключ Groq не используется для обновлений.

## Проверки

`bash scripts/setup-cloud.sh`: успешны `assembleRelease`, `testDebugUnitTest`, `lintDebug`, `lintRelease`; apksigner подтверждает подпись v2 прежним сертификатом.

66 JUnit/Robolectric-тестов, без ошибок и падений:

Проверены автоматическая вставка и замена выделения, вставка исходного текста при сбое очистки, запрет поздних результатов после смены поля, парольные поля, темы, удержание/перетаскивание, область касаний и отсутствие изменения размера приложения. Рендеры Native Graphics проверяют прозрачность области вне микрофона; это не снимки физического телефона.

Тесты обновлений охватывают метаданные/адрес источника, кеш, повреждённые и оборванные загрузки, отмену, размер и хеш, совпадение подписи/пакета/версии, ограниченный FileProvider, read-only URI установщика и полный возврат с экрана разрешения на установку.

Lint: 0 ошибок, 7 предупреждений в каждом варианте сборки: доступная новая версия AndroidX Core, выделение RectF при рисовании и 5 замечаний к локализации русских строк. Они не скрыты.

`prepare-release.py` выполнен дважды с одинаковым результатом. Он проверяет сертификат и версии, подготавливает неизменяемый версионный APK и `latest.json` для совместной публикации. `verify-update-channel.py` после публикации проверяет настоящий Java-клиент через GitHub: загрузку для старой версии, хеш/кеш и ответ для уже актуальной версии. Проверка не использует ключ Groq.

После публикации коммита `bb0c49e123a47ce6c0efe9f5b4d4ad48dc1360d4` сетевая проверка завершилась успешно: `DOWNLOAD_VERIFIED 1.0.3`, затем `UP_TO_DATE 1.0.3`; скачанный клиентом APK совпал с локальной сборкой побайтно по SHA-256. Отдельное скачивание по прямой GitHub-ссылке на этот коммит также подтвердило размер и SHA-256. Это проверка доставки, а не завершённой установки на устройстве.

## Что проверяется на телефоне

Подключённого Pixel в облачной среде нет. Появление/перетаскивание прозрачного IME в Telegram, взаимодействие с жестами Android, запись реального микрофона и завершение системной установки нужно проверить на устройстве. Успех тестов и сетевой проверки не означает, что установка уже выполнена на телефоне. Живые запросы с личным ключом Groq в этой среде не выполнялись.
