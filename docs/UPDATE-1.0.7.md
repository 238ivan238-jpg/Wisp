# Wisp 1.0.7 — рядом с Gboard, логи и годовая статистика

`app.wisp.voice`, versionCode 8. Совместимое обновление прежним сертификатом. Android API 28+ для прежнего IME; новый помощник требует API 33+ и ручного включения службы в специальных возможностях Android.

## Печатать в Gboard и диктовать через Wisp

Раньше Wisp был выбранным методом ввода; для ручной правки приходилось переключаться на Gboard. Пользователь явно выбрал автоматическую вставку через специальные возможности. Теперь на Android 13+ Gboard может оставаться выбранной клавиатурой, а Wisp показывает отдельный небольшой микрофон у активного поля. Нажатие начинает/останавливает запись, удержание открывает настройки, перетаскивание сохраняет положение. Широкой панели и дополнительных кнопок нет.

Помощник использует публичные `AccessibilityService.onCreateInputMethod()` и `InputMethod.AccessibilityInputConnection` с `FLAG_INPUT_METHOD_EDITOR`. Служба не запрашивает дерево экрана (`canRetrieveWindowContent=false`), не использует буфер обмена или `ACTION_SET_TEXT`, не меняет выбранную клавиатуру и не вызывает отправку сообщения. Доступ к вводу включается вручную пользователем в Android; Gboard выбирается системным переключателем. Если Android ограничил включение службы у установленного APK, пользователь вручную разрешает ограниченные настройки в сведениях о Wisp. Код не обходит ограничения системы.

Окно микрофона имеет размер 64 dp и `FLAG_NOT_FOCUSABLE`: оно не забирает фокус у редактора/Gboard. Системная навигационная область и вырезы учитываются при позиционировании. Запись выполняется в привязанной службе с foreground-типом `microphone`, объявленными разрешениями и foreground-уведомлением. Аудио записывается только после нажатия; максимум две минуты. После обработки/отмены временное аудио удаляется.

Вставка идёт через системное подключение ввода в текущую позицию курсора с заменой только выделения. Android предварительно завершает composing-текст обычной клавиатуры в одной batch-операции. Существующие слова вокруг вставки остаются на месте. Счётчик слов пополняется только после проверки текста и позиции курсора. При недоступном подтверждении повторной отправки нет: это предотвращает дублирование; неподтверждённые слова не учитываются в статистике. Поля без поддержки нужных API получают сообщение с предложением прежнего режима Wisp.

Смена/перезапуск соединения ввода отменяет запись и ожидающий результат, даже при одинаковом fieldId: приложение может повторно использовать тот же редактор для другого чата. Парольные поля, нулевой тип ввода, заблокированный экран и выбранный прежний IME Wisp исключены. Проверка блокировки выполняется также таймером записи. На Android 9–12 компонент помощника отключён ресурсом; прежняя клавиатура сохраняется.

Поведение API сверено с Android 15 AOSP:

- [InputMethod API для AccessibilityService](https://github.com/aosp-mirror/platform_frameworks_base/blob/android-15.0.0_r1/core/java/android/accessibilityservice/InputMethod.java).
- [Завершение composing-текста и проверка sessionId на стороне редактора](https://github.com/aosp-mirror/platform_frameworks_base/blob/android-15.0.0_r1/core/java/android/view/inputmethod/RemoteInputConnectionImpl.java).
- [Системная привязка службы](https://github.com/aosp-mirror/platform_frameworks_base/blob/android-15.0.0_r1/services/accessibility/java/com/android/server/accessibility/AccessibilityServiceConnection.java).

## Диагностика

В настройках появился раздел «Логи и диагностика»: Android Share для JSON-файла, сохранение через системный выбор документа и отдельная очистка журнала. Сбор локальный/автоматический; отправка по действию пользователя. Автоматического сервера загрузки и прямого соединения с этим чатом нет. Файл можно прикрепить к разговору вручную.

Последние 200 событий содержат время UTC, версию, случайный id сессии, этап/исход, режим, известную модель, длительность, численные счётчики слов, HTTP-статус и код из разрешённого списка. Отмечаются успешный ответ без изменений (`UNCHANGED`), возврат исходника (`FALLBACK`), отмена и неподтверждённая вставка. Запись, распознавание, очистка/перевод, вставка, проверка ключа, скачивание/проверка/передача обновления и ошибки окна имеют отдельные этапы.

Исключения сохраняются как классы и строки исходников приложения (до восьми кадров на причину, до трёх причин). Сообщения исключений, текст диктовки/редактора, аудио, ключи, заголовки, URL и тела запросов/ответов не записываются. Неизвестные коды сервера заменяются на `other`. Непойманная Java-ошибка сохраняется синхронно перед штатным обработчиком; это не гарантирует журнал нативного сбоя, ANR или принудительного завершения процесса.

Экспорт — через отдельный неэкспортируемый FileProvider с read-only разрешением на конкретный файл каталога `cache/diagnostics/`; установщик по-прежнему использует изолированный провайдер `updates`. Хранится до пяти временных JSON-файлов. Очистка журнала не сбрасывает статистику. Старые события до 1.0.7 восстановить нельзя.

## Статистика и дизайн

Периоды — 7, 30 и 365 дней. Дневные агрегаты хранятся 365 дней вместо 90, общие счётчики и имеющиеся данные сохраняются. Годовой график суммирует выбранные 365 календарных дней по месяцам; крайние месяцы могут быть неполными. Нет реконструкции несобранных или ранее удалённых дней. 7/30 дней по-прежнему отображаются по дням, показатели — диктовки/слова/минуты.

Текстовая стрелка заменена векторным значком; значок и подпись «Настройки» центрируются вместе по горизонтали и вертикали. Кнопка доступна как единый элемент для экранного диктора. Подписи оси графика возле последнего значения не накладываются друг на друга.

## Проверки

`bash scripts/setup-cloud.sh` успешно завершил `assembleRelease`, `testDebugUnitTest`, `lintDebug`, `lintRelease`; подпись v2 прежним сертификатом подтверждена. 117 тестов: 0 падений, ошибок и пропусков. Использованы Robolectric API 35 и отдельная проверка API 28.

Проверки охватывают позицию курсора/выделение/существующий текст, многострочный перевод, отсутствующее подтверждение без повторной вставки, отсутствие ложного подтверждения по старому суффиксу, отмену поздних результатов после смены/перезапуска редактора, пароль/блокировку/прежний IME, размер и фокус окна, API-флаг без доступа к дереву экрана и отключение помощника на старом Android. Для журналов проверены отсутствие секретов/текстов/сообщений сервера, ограничение/сохранение, HTTP-ошибка настоящего клиента с фикстурным транспортом, `UNCHANGED`, read-only экспорт/провайдер, кнопки Share/Save, ограничение файлов, очистка и делегирование crash-handler. Статистика проверена на 400 днях с сохранением 365 бакетов и общих сумм; годовой график суммирует 365 тестовых диктовок. Проверены центрирование/действие кнопки возврата. Native Graphics отрисовал экран годовой статистики с тестовыми данными.

Lint: 0 ошибок, 12 предупреждений в каждом варианте: синхронный commit журнала перед crash-handler, доступная новая AndroidX, рекомендация RequiresApi для сервиса, выделение при рисовании микрофона, программный конструктор графика, абсолютная ориентация координат overlay (2), локализация строк (5). Предупреждения не скрыты.

Облачные проверки не включают реальную привязку службы на Pixel, запись аппаратного микрофона, полный цикл с Gboard/Telegram, системные разрешения или живую модель Groq. Новый режим нужно проверить на телефоне. Результаты языковых тестов являются фикстурами, а не оценкой точности перевода/очистки. Прежние сообщения пользователя об отсутствии ожидаемых исправлений не объявляются устранёнными без проверки на устройстве; журнал теперь позволяет проверить этап и ответ модели.
