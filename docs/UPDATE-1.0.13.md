# Wisp 1.0.13 — эмодзи внутри текста

`app.wisp.voice`, versionCode 14. Пользователь отметил, что эмодзи собираются в конце диктовки вместо естественного оформления отдельных мыслей. Системное правило обработки теперь требует связывать каждый добавляемый эмодзи с конкретной фразой, предложением, абзацем или пунктом списка. Добавлены примеры начала эмоционального предложения, позиции внутри предложения и разных позиций рядом с пунктами списка.

Запрещены общий декоративный «хвост», отдельный заключительный абзац из эмодзи и механическое размещение в одном и том же месте. Смайлик после подходящего предложения, в том числе последнего, допустим. Существующие эмодзи не переносятся произвольно; слова, числа, URL, код, маркеры списков и смысл сохраняются. Уместность важнее количества. Для серьёзных тем сохраняется сдержанность.

Настройка остаётся добровольной, её сохранённое значение не меняется. Правило применяется в том же запросе очистки/перевода и при резервной модели; дополнительных запросов, изменения Whisper и клиентской перестановки эмодзи нет. Проверки транспорта проходят по примерам русского/английского текста с эмодзи в начале, середине и списках. Фикстурные ответы не являются проверкой качества живого Groq; стиль следует оценить на реальных диктовках после восстановления доступа к API.

Сетевой код не изменялся. Обновление не обещает устранить HTTP 403: такой ответ означает отказ в доступе и требует проверки сети/аккаунта/доступности операции. VPN как причина конкретного отказа не подтверждён. Восстановление неудачной записи пока не реализовано; оно включено в предложения для обсуждения в [IDEAS.md](IDEAS.md).

`bash scripts/setup-cloud.sh`: release-сборка и подпись v2 успешны, 148 тестов — 0 падений, ошибок и пропусков. Lint debug/release: по 0 ошибок и 12 предупреждений. Расширены фикстуры размещения эмодзи для обоих языковых режимов; передача Unicode и многострочных списков сохраняется без дополнительных запросов. Издатель проверил прежний сертификат, пакет и версию.
