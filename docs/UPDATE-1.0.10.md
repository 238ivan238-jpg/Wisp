# Wisp 1.0.10 — быстрый перевод под микрофоном

`app.wisp.voice`, versionCode 11. Под основным микрофоном добавлена маленькая соединённая с ним кнопка EN. Верхний микрофон записывает обычную диктовку без перевода, EN — одну запись с переводом на английский. Режим выбирается при запуске и сохраняется до завершения обработки. Нажатие любой кнопки во время записи останавливает её, сохраняя исходный выбор режима. Во время обработки обе кнопки отключены.

При записи для перевода основной значок показывает стоп-индикатор с EN, подпись таймера начинается с EN; при обработке EN сохраняется возле индикатора ожидания. Режим не меняет язык распознавания или пользовательские настройки. Верхняя кнопка использует clean/raw; нижняя использует translate, даже если обычная обработка выключена. Эмодзи применяются по сохранённой настройке. Текст вставляется после обработки, сообщения не отправляются.

Постоянный переключатель перевода в настройках заменён пояснением о кнопке EN. Старый сохранённый translate трактуется как clean для обычного микрофона; raw остаётся raw. Ключ, словарь, статистика и настройка эмодзи сохраняются. Это намеренное изменение выбора перевода: теперь его определяет кнопка для каждой записи.

Оба сервиса используют общий VoiceControls размером 64 × 112 dp: основной круг 64 dp, нижняя кнопка 48 × 48 dp с подписью EN. Перетаскивание любой кнопки перемещает всю пару и сохраняет позицию; удержание открывает настройки. Светлая/тёмная системная монохромная тема сохраняется. Положение ограничено по полному размеру пары с учётом системных панелей/вырезов. В прежнем IME регион касаний включает обе кнопки; остальной экран не закрывается панелью клавиатуры. Окно рядом с Gboard остаётся небольшим и не забирает фокус.

Лимит пять минут, защита парольных полей, отмена при смене редактора, журналирование, статистика и проверка подписанных обновлений сохранены. Журнал и статистика получают выбранный режим каждой записи, поэтому перевод не учитывается как удаление русских слов-паразитов.

Облачные проверки используют Robolectric/фикстуры; запись аппаратного микрофона Pixel, реальная вставка рядом с Gboard и качество перевода живой моделью требуют проверки на телефоне. Синтетический маркер ключа в тестах не расшифровывается и не позволяет выполнить реальный запрос Groq.

Проверка `bash scripts/setup-cloud.sh`: release-сборка и подпись v2 успешны, 130 тестов — 0 падений, ошибок и пропусков. Проверены старт EN/возврат к raw без изменения настроек, фиксация режима до остановки, удержание/перетаскивание нижней кнопки без случайной записи, безопасные границы overlay, обе кнопки в touch-регионе, отключение при пароле/обработке и миграция старого translate. Native Graphics отрисовал обычный значок, запись и запись с EN; снимок просмотрен. Издатель проверил прежний сертификат и метаданные APK.

`lintDebug`/`lintRelease`: по 0 ошибок и 13 предупреждений. К 12 прежним добавилось предупреждение ClickableViewAccessibility о setOnTouchListener на стандартной Button. Кнопка наследует performClick, жесты вызывают его для короткого нажатия, действия также назначены через OnClickListener; нажатия/удержание/перетаскивание проверены тестами. Предупреждение не скрывалось.
