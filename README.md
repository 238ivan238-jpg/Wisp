# Wisp для Pixel 9

Личная Android-клавиатура для русской и английской диктовки. Запись → Groq Whisper → необязательная ИИ-очистка → предпросмотр → вставка в активное поле. Собственного сервера и подписки Wisp нет. Нужны интернет и ваш аккаунт/API-ключ Groq; его условия, тарифы и ограничения действуют отдельно.

## Установка на телефон

1. Скачайте актуальный `downloads/Wisp-1.0.2.apk` на Pixel 9 и откройте файл. Если Android попросит, разрешите установку приложений этому браузеру или файловому менеджеру. После установки разрешение можно выключить. Обновление ставится поверх предыдущих версий с тем же сертификатом подписи; удалять приложение для обновления не требуется.
2. Откройте **Wisp**, разрешите микрофон, нажмите **«Включить Wisp в настройках Android»**, затем **«Выбрать клавиатуру Wisp»**. Предупреждение Android о доступе клавиатуры к вводу стандартно для IME.
3. Создайте ключ на [console.groq.com/keys](https://console.groq.com/keys), введите его в Wisp, нажмите **«Сохранить»**, затем **«Проверить»**. Проверка обращается к списку моделей и отправляет короткую фиксированную фразу для ИИ-очистки. Голос не записывается; качество распознавания речи проверяется отдельно диктовкой. Применяются условия Groq, в том числе оплата запросов и лимиты.
4. Коснитесь тестового поля внизу экрана. Короткое нажатие микрофона начинает запись, следующее заканчивает её. Или удерживайте микрофон дольше 350 мс и отпустите. Говорите хотя бы секунду; максимум — две минуты.
5. Проверьте результат и нажмите **«Вставить»**. Приложение самостоятельно не нажимает «Отправить». Возврат к Gboard — **◎**, удержание этой кнопки — выбор клавиатуры.

## Что умеет

- `RU + EN` — автоопределение для смешанной речи; нажатием можно выбрать RU или EN.
- Режимы **Чистый → Письмо → Заметка → Без ИИ** переключаются в клавиатуре.
- Можно сравнить очищенный текст с исходным и вставить выбранный вариант. Если очистка не сработала, исходная расшифровка остаётся доступной с сообщением об ошибке.
- Словарь имён и терминов, выбор Whisper Large v3 или Turbo в настройках.
- **↶** отменяет последнюю вставку, только если текст перед курсором всё ещё совпадает и выделения нет. Отмена замены выделенного текста не поддерживается. Перемещение в другое поле сбрасывает состояние.
- Пробел, Enter с учётом действия поля, удаление выделения или одного Unicode code point, автоповтор удаления, вспомогательная буквенная RU/EN-клавиатура. Полного функционала Gboard, автокоррекции, свайпов и эмодзи-панели здесь нет.
- Микрофон отключён в полях, которые приложение помечает как пароль. Отмена, скрытие клавиатуры или смена поля прерывают запись/запрос и сбрасывают результат; поздний сетевой ответ не вставляется в другое поле.

## Данные

API-ключ шифруется AES-GCM; ключ шифрования создаётся в Android Keystore. Расшифровка ключа нужна только для HTTPS-запросов к `api.groq.com`. В APK ключа нет. Резервное копирование и перенос данных приложения выключены. История диктовок на диске не ведётся; временный аудиофайл удаляется после обработки или отмены. После аварийного завершения оставшийся файл удаляется при следующем запуске службы клавиатуры. Исходный/очищенный текст находится в памяти до вставки, новой записи или закрытия клавиатуры.

Начиная с 1.0.1, скриншоты экрана настройки разрешены. Сохранённый ключ не подставляется в поле, ввод скрыт точками. Сообщения об ошибках не выводят ключ или ответ сервера целиком. Проверка различает HTTP 401 (ключ не принят) и HTTP 403 (доступ запрещён, причина не обязательно в ключе). Пробелы и невидимые разделители при копировании ключа удаляются перед сохранением и отправкой.

В 1.0.2 основная модель очистки — `openai/gpt-oss-20b`, параметр ограничения — `max_completion_tokens`, для GPT-OSS задан `reasoning_effort: low`, согласно официальному SDK Groq. При явной ошибке недоступной/выведенной из эксплуатации модели приложение запрашивает `/models` и пробует только перечисленные там поддерживаемые альтернативы. Ошибки авторизации, обычный запрет доступа, лимиты и некорректные параметры не запускают перебор моделей. Точный HTTP-статус и безопасный идентификатор ошибки отображаются без тела ответа. Отказ очистки по-прежнему оставляет исходную расшифровку доступной.

Аудио передаётся **Groq** для распознавания, а расшифровка — для ИИ-очистки, если выбран соответствующий режим. Отмена не может отозвать уже отправленные провайдеру данные. Хранение данных у Groq определяется его политикой. Оффлайн-распознавание в эту версию не включено.

## Сборка

Java 17+, Android SDK platform 35, Build Tools 35.0.0; Gradle Wrapper 8.11.1 и AGP 8.9.2 закреплены в проекте. Интерфейс и служба написаны на Java, без сторонних UI-библиотек; Kotlin не нужен для этой реализации. Минимальная версия Android — 9 / API 28; основной целевой телефон — Pixel 9 с Android 15+.

В подготовленной облачной среде:

```bash
cd /workspace/Wisp
bash scripts/setup-cloud.sh
```

Скрипт устанавливает инструменты в `/workspace/.wisp-tools`, проверяет опубликованные контрольные суммы архивов, сохраняет TLS-проверку, использует системные CA и предоставленный HTTPS-прокси. Он не требует прав root. Локальный сертификат подписи находится в игнорируемой `.local/debug.keystore`. Личная release-сборка подписана этим сертификатом, отладка в ней выключена. Для обновления приложения поверх установленного сохраняйте этот файл; без него понадобится удаление старой версии, что удалит её настройки. Не публикуйте ключ подписи вместе с исходниками. Эта конфигурация подписи предназначена для личной установки, не для Google Play.

Для последующих команд:

```bash
source scripts/cloud-env.sh
./gradlew assembleRelease testDebugUnitTest lintDebug lintRelease
```

В Android Studio откройте корневую папку, укажите SDK и используйте JDK 17 или 21. Для первоначальной генерации локального сертификата можно выполнить `keytool` из `scripts/setup-cloud.sh` или локально скорректировать путь подписи. Не передавайте в сборку API-ключ Groq: он вводится в готовом приложении.

## Проверки и ограничения

JUnit проверяет формирование multipart и JSON-запросов, RU/EN, режимы, ошибки HTTP, пустые/обрезанные ответы, сохранение исходного текста и отмену. Robolectric под Android API 35 проверяет экран настройки, парольные поля, раскладку, смену поля и отбрасывание поздних ответов. Native Graphics создаёт изображения интерфейса в `app/build/reports/screenshots/`; это рендеры JVM, не скриншоты физического Pixel.

Реальное качество распознавания, доступность облачных моделей для вашего ключа, микрофон Pixel и взаимодействие с конкретными приложениями требуют проверки на телефоне. Ключа пользователя и подключённого Pixel в среде сборки нет; эти проверки не заменяются unit-тестами. При обновлении моделей Groq идентификаторы находятся в `GroqClient.java`.
