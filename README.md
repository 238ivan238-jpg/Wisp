# Wisp для Pixel 9

Личный голосовой ввод для Android: плавающий микрофон вместо панели клавиатуры. Нажатие начинает запись, повторное нажатие останавливает её; после распознавания и необязательной ИИ-очистки текст автоматически вставляется в активное поле. Сообщение автоматически не отправляется.

## Установить 1.0.3 один раз

1. Скачайте `downloads/Wisp-1.0.3.apk` и установите поверх предыдущего Wisp. Сертификат тот же, настройки и ключ сохраняются. Первоначальное разрешение на установку даётся тому браузеру или файловому менеджеру, из которого открыт APK.
2. Откройте Wisp, разрешите микрофон, включите Wisp в настройках методов ввода Android и выберите его. Уже выданные разрешения заново выдавать не нужно.
3. Для распознавания нужен ваш ключ [Groq](https://console.groq.com/keys). Введите его в приложении, сохраните и проверьте. Ключ не нужно передавать разработчику. Проверка отправляет короткую фиксированную фразу для проверки очистки и читает список моделей; голос не записывается. Действуют тарифы и лимиты Groq.
4. Коснитесь текстового поля в нужном приложении: появится только плавающий микрофон. Нажмите, говорите, нажмите ещё раз. Записывайте хотя бы секунду; максимум — две минуты. Во время записи видны таймер и индикатор. После обработки текст вставится сам, без предпросмотра и кнопки «Вставить».
5. Перетаскивайте микрофон, чтобы изменить его положение. Удержание значка открывает настройки. Для обычного ввода используйте системное переключение клавиатуры на Gboard. Своей второй кнопки переключения у Wisp нет.

Wisp остаётся выбранным методом ввода Android. Плавающий значок появляется при работе с текстовым полем, а не постоянно поверх всех приложений. Широкой панели нет; область за значком прозрачна и должна пропускать касания. Для этого используются публичные API InputMethodService, без Accessibility Service и разрешения «поверх других приложений». В полях, помеченных приложением как пароль, диктовка отключена.

## Дальше обновляться внутри приложения

Откройте Wisp или удерживайте микрофон → **«Проверить обновления»** → **«Скачать и обновить»**. Новая версия загружается самим приложением. В первый раз Android может попросить разрешить Wisp установку приложений; после возврата установка продолжится с уже загруженным APK. В системном окне подтвердите обновление.

Включённая по умолчанию автопроверка срабатывает при открытии настроек Wisp, не чаще одного раза в шесть часов; ручная проверка доступна всегда. В фоне без открытия приложения проверка не выполняется. Скачивание начинается по кнопке. Никакой оплаты или API-ключа для обновлений нет. Доступ к GitHub и интернет всё равно нужны.

Перед установкой проверяются размер, SHA-256, идентификатор/версия пакета и совпадение сертификата с установленным Wisp. Повреждённый APK, откат версии, чужой пакет или другой подписант не передаются установщику. Повторное нажатие использует проверяемый кеш, если версия уже скачана. Включение функции требует один раз установить 1.0.3 вручную: в старых APK этой функции нет.

## Настройки и внешний вид

- Светлый режим системы: белая основа, чёрные элементы. Тёмный: чёрная основа, белые элементы. Цветных акцентов нет. Плавающий микрофон контрастный; остальная область прозрачна.
- Язык и обработка выбираются в настройках: авто RU/EN, русский, English; чистый текст, письмо, заметка, без ИИ.
- Есть словарь имён/терминов и выбор Whisper Large v3 или Turbo.
- Клавиатурная панель, заголовок, языковые кнопки, ABC, предпросмотр, отмена, пробел, удаление и Enter убраны по запросу пользователя. Для ручной правки остаётся обычная клавиатура телефона.
- Если очистка не удалась, вставляется исходная расшифровка и показывается сообщение об ошибке. При смене поля, скрытии метода ввода или закрытии службы запрос отменяется; поздний результат не вставляется в другое поле.

## Данные

API-ключ защищён AES-GCM и Android Keystore. Сохранённый ключ не подставляется обратно в поле; ввод скрыт. Скриншоты разрешены. Ключа в APK и GitHub нет. Резервное копирование/перенос данных отключены. История диктовок не ведётся. Временное аудио удаляется после обработки/отмены; после аварийного завершения остатки удаляются при следующем запуске службы. Переключение темы или ориентации прерывает текущую запись и перестраивает интерфейс.

Для распознавания аудио передаётся Groq Whisper; для выбранного режима очистки текст передаётся текстовой модели Groq. Основная — `openai/gpt-oss-20b`, с совместимыми альтернативами при явном отказе из-за модели. Отмена не отзывает уже отправленные данные. Хранение у Groq определяется его политикой; оффлайн-распознавание не реализовано. Клиент обновлений обращается только к GitHub и никогда не получает ключ Groq или текст диктовки.

## Сборка

Java 17/21, Android SDK 35, Build Tools 35.0.0, Gradle Wrapper 8.11.1, AGP 8.9.2. Минимальная версия Android — API 28; целевой телефон — Pixel 9 с Android 15+. AndroidX Core используется для безопасной передачи APK системному установщику через FileProvider.

```bash
cd /workspace/Wisp
bash scripts/setup-cloud.sh
```

Скрипт устанавливает инструменты в `/workspace/.wisp-tools`, проверяет опубликованные контрольные суммы архивов, сохраняет проверку TLS и использует системные CA/предоставленный прокси. Затем собирает приложение, запускает тесты и Lint. Сборочный APK лежит в `dist/Wisp-<версия>.apk`.

```bash
source scripts/cloud-env.sh
./gradlew assembleRelease testDebugUnitTest lintDebug lintRelease
```

Приватный сертификат подписи — в игнорируемой `.local/debug.keystore`. Он нужен для совместимых обновлений. Не публикуйте его или пароли в архиве исходников. Эта личная release-сборка не отладочная, но не настроена для публикации в Google Play.

## Выпустить следующую версию

1. Увеличить `versionCode` и `versionName` в `app/build.gradle`.
2. Успешно выполнить `bash scripts/setup-cloud.sh`.
3. Выполнить `python3 scripts/prepare-release.py --notes 'Что изменилось для пользователя'`. Скрипт проверит прежний сертификат, версии и целостность APK, скопирует артефакт и создаст `downloads/latest.json`.
4. Зафиксировать APK и `downloads/latest.json` одним коммитом, опубликовать в ветку `codex/wisp-android-v1` без force-push и выполнить `python3 scripts/verify-update-channel.py`. Скрипт проверяет реальное скачивание клиентом обновления и совпадение с локальным APK. Установка приложения на телефон этим действием не выполняется.

Адрес канала обновлений встроен в установленные версии. Не удаляйте ветку и не заменяйте опубликованные APK другим содержимым под тем же номером. Изменения должны выходить новым номером версии. Повторная подготовка той же неизменённой сборки безопасна.

## Проверки и практические границы

JUnit/Robolectric проверяют запросы Groq, сбои очистки, автоматическую вставку, смену поля, парольные поля, темы, удержание/перетаскивание и область касаний плавающего микрофона. Для обновлений проверяются метаданные, кеш, повреждённые загрузки, подписи, URI установщика и возврат с экрана разрешений. Native Graphics создаёт рендеры в `app/build/reports/screenshots/`; это не снимки физического телефона.

Полное поведение плавающего метода ввода в Telegram/других приложениях, запись на Pixel и системное подтверждение установки необходимо проверить на самом телефоне. В среде нет подключённого Pixel и ключа пользователя; JVM-тесты не выдаются за проверку оборудования. Результаты 1.0.3 — в `docs/UPDATE-1.0.3.md`. Ранее реальное распознавание на телефоне было подтверждено пользовательским снимком.

Историческое сравнение первых вариантов: [docs/COMPARISON.md](docs/COMPARISON.md).
